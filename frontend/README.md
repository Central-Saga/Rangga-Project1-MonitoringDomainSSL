# Frontend - Sistem Monitoring Domain, Hosting & SSL

Folder ini berisi antarmuka pengguna (Next.js) untuk Sistem Monitoring Domain, Hosting, dan SSL.

## 🛠️ Teknologi
*   Next.js (React Framework)
*   TypeScript
*   Tailwind CSS

## 💻 Cara Menjalankan Frontend
1. Masuk ke folder ini: `cd frontend`
2. Install dependensi: `npm install`
3. Copy file environment (jika ada): `cp .env.example .env.local`
4. Sesuaikan URL API backend di dalam file `.env.local`
5. Jalankan server development: `npm run dev`
6. Buka `http://localhost:3000` di browser.
